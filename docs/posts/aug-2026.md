# Wiki Updates

- Added **[URL Search Support](https://i.ibb.co/kVdvPwnc/image.png)** / [2](https://i.imgur.com/v13FI4y.png), you can now search entire URLs or text inside URLs. Disabled by default, press the link icon in the search bar to enable. TY to @Lou, @Manu, & @Bread for making this happen.

- Added a **[Semantic Style Search](https://search.fmhy.bid/)** for FMHY, should work well with natural language. TY to @Zenith for making this.

- Added a new theme called [Monolith](https://i.ibb.co/QjFYWTw9/image.png) / [2](https://i.imgur.com/fwZMOCw.png). Uses JetBrains Mono, targeted at HiDPI monitors. TY to @Zenith for making this.

- Added a [RSS Style Changelog Tracker](https://d.fmhy.bid/rss.xml). Thank you to @Zenith for making this.

- Split Reading Recommendations into 3 subsections: [Books](https://fmhy.net/reading#book-recommendations) / [Comics](https://fmhy.net/reading#comic-recommendations) / [Manga](https://fmhy.net/reading#manga-recommendations). TY to @Dan for doing this.

- Added section for [IPTV Players](https://fmhy.net/video#iptv-players) to Video Tools, TY to @RansomQ for doing this.

- Added section for [TikTok Tools](https://fmhy.net/social-media-tools#tiktok-tools) to Social Media.

- Re-ordered stream aggregators based on the results (and conversations) that took place during [the polls for it](https://challonge.com/rtdxi8qg/fullscreen). Thank you to everyone who voted. [Before vs After](https://i.ibb.co/VYsz7PbR/Untitled.png) / [2](https://i.imgur.com/XS9RUNN.png)

- Re-ordered Game Repack Sites based on the results from the poll, thank you to everyone who voted. [Before vs After](https://i.ibb.co/MyyqwQ6z/image.png) / [2](https://i.imgur.com/shPiyop.png)

- Changed the currently focused search and scroll-to-match highlights to use [theme colors](https://i.ibb.co/39z3CZDv/image.png) / [2](https://i.imgur.com/UNHsaiZ.png).

# Stars Added ⭐

- Starred [Octave](https://fmhy.net/audio#streaming-sites) in Browser Music (and iOS Audio), high quality ad-free audio streaming, has cloud sync, unlimited skips, last.fm integration, library importing, a equalizer, offline downloads, and more.

- Starred [0807](https://fmhy.net/file-tools#file-hosts) in File Hosts, 10GB, keeps files 90 days (after last download), has a good dev team + has been well received so far.

- Starred [ZeiGames](https://fmhy.net/gaming#download-games) (formerly RexaGames) in Game Downloads, big library, fast hosts, update games quickly. 

- Starred [LoLROMs](https://fmhy.net/gaming#rom-sites) in ROM section, newer collection, covers both popular and obscure consoles, has thousands of games + single click downloads.

- Starred [Thunderstore](https://fmhy.net/gaming-tools#game-mods) is Game Mods, mods + mod manager mostly for Unity Games (but has others too), has a big library, preferred over Nexus by some. 

- Starred [StoryGraph](https://fmhy.net/reading#book-tracking-databases) in Book Recommendations, book tracking / recommendation site, very feature rich, preferred over GoodReads by some.

- Starred [Comic Book Reading Orders](https://fmhy.net/reading#comic-recommendations) in Comic Recommendations, massive catalog of reading orders, going all the back to the 60's. 

- Starred [The Book Prize Index](https://fmhy.net/reading#book-recommendations), nice index of book awards + award winning books.

- Starred [OptiScaler](https://fmhy.net/gaming-tools#optimization-tools) in Optimization Tools, game upscaling tool for windows, uses games motion vectors for better results, has no screen warping like Lossless Scaling.

- Starred [MKV BASE](https://fmhy.net/video#download-sites) in Movies/TV Downloading, has very big library + good hosts.

- Starred [Yeanime](https://fmhy.net/video#anime-streaming) in Anime Streaming, has a nice UI, fast streams, seems to be well liked.

- Starred [Bypass (lc)](https://fmhy.net/internet-tools#redirect-bypass) in Redirect Bypass, works well, supports many sites.

- Starred [Startpage](https://fmhy.net/privacy#search-engines) in Privacy Search Engines, essentially a google frontend with better privacy, has better results in some cases than other privacy engines.

# Things Removed

- Removed Cromite as its now 3 major chromium versions behind, has many bugs, and the dev has said they're taking a break, we'll re-add in the future if it makes a comeback.

- Added Nightcord to our unsafe list, they seem to of been caught [logging discord tokens](https://i.ibb.co/gbG0SYhM/image.png) in the past. Note we didn't have this listed on FMHY, we just want to help get the info out there.
